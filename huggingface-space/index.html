Kimss Forge

MIT agent harness: local tools and MCP, any OpenAI-compatible model, no account. Production is one argument: gateway="kimss".

Kimss AI (kimss.ai) is not Kimi, the LLM family by Moonshot AI. Different company, different category.

pip install kimss-forge
from kimss_forge import Agent, tool

@tool
def multiply(a: float, b: float) -> float:
    return a * b

agent = Agent(model="gpt-4o-mini", tools=[multiply])
print(agent.run("What is 6 times 7?"))
